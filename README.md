# Red Dirt Hairy Legged Alabama Country Boy

A Next.js 15 website built with a full Southern Americana theme.

## Assets
- Custom circular photorealistic icon (rope border, country boy with shotgun & tattoo)
- Full-width cinematic header banner (Alabama autumn sunset scene)
- Muted grassy field web page background
- Shotgun shell buttons with fired/unfired hover states
- Favicon package

## Stack
- Next.js 15 + React 19 + TypeScript
- Tailwind CSS
- shadcn/ui components
- Rye (Google Font) for Western typography

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Image Assets
Header banner, background, and icon images are served from CDN.  
Shell button PNGs are in `public/`.
